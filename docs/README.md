# Alejuego — Documentación

Juego de navegador diario de fútbol: se muestran dos futbolistas y hay que encontrar un camino entre ellos saltando entre jugadores y clubes-temporada en los que coincidieron.

Estado del proyecto: **Fase 2 — Documentación** (ver [process/workflow.md](process/workflow.md)).

## Cómo leer estos documentos
- Cada hoja trata **un solo tema**.
- Lo marcado como **[ABIERTO]** es una decisión pendiente y está listado en [process/open-questions.md](process/open-questions.md).
- Lo marcado como **[PROPUESTO]** es una propuesta de Claude que el dueño del proyecto aún no confirmó.
- Los documentos son vivos: cualquier cambio de decisión se refleja aquí antes de tocar el código.
